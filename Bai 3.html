I. Giới thiệu về HTML

HTML = HyperText Markup Language – ngôn ngữ cơ bản nhất để xây dựng các trang web. HTML do Tim Berners-Lee phát minh và được W3C đưa thành chuẩn năm 1994.

  • HTML dùng các thẻ (tags) để định dạng cách hiển thị dữ liệu.
  • Trình duyệt thường không báo lỗi cú pháp; viết sai chỉ hiển thị sai ý định.
  • Tập tin HTML là dạng text, lưu đuôi .html hoặc .htm.
  • Soạn bằng Notepad, Notepad++, FrontPage, Dreamweaver…

Ví dụ: cùng dữ liệu nhưng định dạng khác nhau

Mã HTMLHiển thị trên trình duyệt
This is webpageThis is webpage
<b> This is webpage </b>This is webpage

Quy tắc về thẻ

  • Thẻ có thẻ mở và thẻ đóng (thêm dấu /): <thẻ> dữ liệu </thẻ>
  • Không phân biệt hoa thường: <HTML> = <html>
  • Khoảng trắng thừa và dấu xuống dòng trong mã nguồn bị bỏ qua:

Xin chào tất cả các bạn lớp K08406

II. Cấu trúc của một tài liệu HTML

<HTML>
  <HEAD>
    <TITLE> Đây là tiêu đề của trang web </TITLE>
  </HEAD>
  <BODY>
    Xin chào tất cả các bạn
  </BODY>
</HTML>

Một thẻ có 3 phần: tên thẻ, thuộc tính, giá trị thuộc tính.

Mã HTMLHiển thị
<FONT FACE="Arial" SIZE="4"> This is a webpage </FONT> This is a webpage

5. Thẻ IMG (không có thẻ đóng)

Thuộc tính: src, width, height, alt, align. Khi dùng ảnh thật: <img src="anh1.jpg" width="200" height="150" alt="Ảnh 1">

Ảnh bên trái được căn align="left", chữ chạy vòng quanh bên phải. Thuộc tính alt hiển thị mô tả khi ảnh bị lỗi.

VI. Tạo bảng trong HTML

  • CAPTION: tiêu đề bảng; BORDER: độ dày viền
  • WIDTH, HEIGHT: pixel hoặc %
  • CELLSPACING: khoảng cách giữa các ô; CELLPADDING: khoảng cách từ biên đến nội dung
  • BGCOLOR, BACKGROUND: màu nền, ảnh nền
  • TR: dòng; TH: ô tiêu đề; TD: ô dữ liệu; ô trống dùng &nbsp;

VIII. Thẻ marquee

  • direction: left (mặc định), right, up, down
  • behavior: scroll, slide (chạy 1 lần rồi dừng), alternate (chạy qua rồi chạy lại)
  • scrollamount: tốc độ (số nguyên)
  • loop: 1 = lặp một lần, -1 = lặp liên tục
